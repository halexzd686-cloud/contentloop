# ContentLoop V1 — Start Here

## Package structure

- `AGENTS.md` — coding-agent operating contract
- `docs/ContentLoop_PRD_v1.md` — product scope
- `docs/ContentLoop_data-model_v1.md` — data model
- `docs/ContentLoop_design_v1.md` — visual and interaction system
- `docs/ContentLoop_implementation-plan_v1.md` — 3–4 week implementation plan
- `docs/progress/` — milestone summaries created during development
- `prompts/bootstrap-prompt.md` — first-message template for Codex / Kimi Code / Claude Code

## Recommended first step

Place this entire folder structure at the root of the ContentLoop repository.

Then send the coding agent the contents of `prompts/bootstrap-prompt.md` and ask it to begin **M0 — Foundation only**.

Do not ask it to build the entire application in one turn.
